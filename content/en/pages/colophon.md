## Fonts

- **Georgia** — main text. The system serif stack.
- **System grotesk** — interface: header, footer, labels.
- **IBM Plex Mono** — monospace accent. Self-hosted, OFL license,
  Latin and Cyrillic subset.

## Tools

- **Eleventy 3.1.7** — static site generator.
- **Node.js 22** — the only build runtime.
- **CSS** — handwritten. No frameworks, no preprocessors.
- **git** — version control.

## Hardware

- **AMD A4-4020**, 8 GB of RAM.
- **Ubuntu 26.04.1 LTS**.

Development happens on this very machine. If the build works here —
it works everywhere.
