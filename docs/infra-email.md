# Пошта: `hello@koztechie.fyi`

**Статус:** крок 128 PLAN ✅. Канал на Zoho Mail Free налаштовано й перевірено
зовнішнім тестом; DNS ведеться в Netlify.
Сторінка `/contact/` уже реалізована; цей документ — інструкція для налаштування самого каналу.

**Канон:** `DECISIONS.md` §263 — «Єдиний канал: `hello@koztechie.fyi`».

## 2. Що зроблено поза репозиторієм

Прямий прийом пошти налаштовано в Zoho Mail Free, а записи доменної зони
`koztechie.fyi` додано в Netlify DNS.

У зоні `koztechie.fyi` налаштовано CAA `0 issue "letsencrypt.org"` і
`0 issuewild "letsencrypt.org"`. Поточний `zmail` DKIM ще має 1024-бітний
RSA-ключ; перегенерація ключа в Zoho та заміна TXT у Netlify DNS очікують
авторизованого доступу до Zoho Admin.

`koztechie.pp.ua` — лише alias із вхідним форвардингом ImprovMX; відправлення
з цього домену не налаштовано. Для нього SPF встановлено в `v=spf1 -all`, а
DMARC — у `p=reject`. MX ImprovMX залишаються для прийому та пересилання.

## 3. Оберіть один шлях

### Шлях A. Прямий прийом у Proton (відхилено через бюджет)

**Умова:** план Proton з підтримкою власного домену (Mail Plus і вище).

Цей шлях не використовується: він платний і суперечить вимозі 100% безплатного
рішення.

1. Proton → **Settings → Domains → Add custom domain** → ввести `koztechie.fyi`.
2. Proton згенерує MX-записи (типу `10.mail.proton.me`… — брати ЗНЯТІ з Proton значення).
3. Доменна зона `koztechie.fyi` (де ведеться DNS — Netlify, див. `PLAN` крок 158):
   - **MX** → значення з кроку 2 (пріоритети — як у Proton).
   - **SPF** (TXT) → `v=spf1 include:spf.proton.me -all` — якщо Proton його дає.
   - **DKIM** (TXT) → значення з Proton.
4. Додати адресу `hello@koztechie.fyi` у Proton (Add mailbox / address).
5. Дочекатися статусу Verified у Proton (перевірка DNS може займати до 48 год).
6. Надіслати тестового листа на `hello@koztechie.fyi` → перевірити прийом у Proton.

**Перевага:** листи нікуди не пересилаються через треті сервіси — прийом напряму.

### Обраний шлях. Безплатний прямий прийом у Zoho Mail Free

Офіційна сторінка Zoho вказує для Free plan один домен, до 5 користувачів і
5 ГБ на користувача; доступ — через webmail, без IMAP/POP/ActiveSync.
Безплатний план доступний лише в окремих дата-центрах, тому його доступність
потрібно підтвердити під час реєстрації:
<https://www.zoho.com/mail/zohomail-pricing.html>

1. Створити організацію Zoho Mail Free та додати `koztechie.fyi`.
2. У **Netlify DNS** додати verification TXT, MX, SPF і DKIM зі значень Zoho.
3. Створити скриньку `hello@koztechie.fyi`.
4. Додати DMARC:
   `v=DMARC1; p=quarantine; rua=mailto:hello@koztechie.fyi; adkim=s; aspf=s`.
5. Надіслати зовнішній тестовий лист, відповісти з Zoho та перевірити
   `Authentication-Results`: SPF/DKIM/DMARC повинні мати `pass`.

**Результат:** скриньку `hello@koztechie.fyi` створено, DNS підтверджено,
зовнішній лист прийнято, відповідь надіслано, а доставність перевірено за
заголовками автентифікації. Канал можна публікувати як працездатний.

### Шлях C. Форвардинг (не обирати для цього каналу)

Cloudflare Email Routing або ImprovMX можуть безплатно пересилати листи, але
не створюють скриньку і не забезпечують відповідь з `hello@`. Цей шлях не
відповідає вимозі прямого прийому та тесту відповіді.

## 4. Верифікація після налаштування

1. MX-записи: `dig MX koztechie.fyi +short` → повертає очікувані записи.
2. Тест: надіслати лист зовнішньою адресою → лист приходить на обраний шлях.
3. Відповідь із Zoho → лист доходить відправнику (доставність, не спам).
4. Термін відповіді читачам — до 7 днів (§324).

## 5. G-01 і D-01

`npm run live-probe` запускає `scripts/email-dns-gate.mjs`: MX≥1, SPF TXT,
DKIM TXT для selector `EMAIL_DKIM_SELECTOR` (типово `zmail`), `_dmarc` TXT і
валідний `security.txt Contact`. Для production перевірки ці DNS-записи мають
бути публічно доступні.

```bash
npm run test:email-dns-gate
```

D-01 перевіряє відсутній MX в ізольованій DNS fixture-зоні. D-01-ext ін’єктує
порожній `zmail._domainkey` у пам’яті та підтверджує, що G-01 завершується
ненульовим кодом; ця перевірка входить до `npm run qa:all`.

## 6. Безпека

- 2FA на Zoho та Netlify — увімкнути й перевіряти під час квартального огляду.
- Записи DNS оновлювати з резервною копією зони (експорт перед зміною).
- Зона `koztechie.pp.ua` керується Netlify DNS на NS `dns*.p04.nsone.net`;
  поточні SPF/DMARC та MX ImprovMX описані вище.
- Не залишати проміжних MX-записів від попереднього хостингу — дублі прийому.
