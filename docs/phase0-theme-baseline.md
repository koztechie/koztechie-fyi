# Phase 0 — рішення й базовий стан

Зафіксовано: 2026-11-16
Гілка: `phase0-theme-decisions`

## Межі фази

- Під час фази заморожено зміни опублікованого контенту.
- На початку роботи дерево вже містило незакомічені зміни з попередньої роботи; їх збережено при створенні гілки, без перенесення чи відкату.
- Цей документ фіксує рішення та вихідний стан. Редизайн і зміни контенту сюди не входять.

## Рішення

| Питання | Рішення |
|---|---|
| `theme-color` | `--paper` (`#FAFAFA`): системна рамка лишається світлою й відповідає основному полотну сайту. |
| NICHLYST і Кладовище | Рішення Phase 0 про світлі сторінки замінено Phase 3: їхній вміст використовує локальний нічний scope, спільні шапка й підвал лишаються світлими. |
| Логотип NICHLYST | Не змінювати кольори чи форму. Це ідентичність гри; застосовувати оригінальний ресурс. |
| Власник темного режиму | Темні візуальні матеріали є сталими за роллю контенту, не залежать від `prefers-color-scheme`. Вебсайт лишається у світлій схемі. |
| Мінімум для `--ink-dim` | 14 CSS px (`0.875rem`, токен `--text-sm`). Його значення `#545454` забезпечує AAA ≥7:1 на `--paper`. |

## Результат Phase 1

- `themes.css` став єдиним джерелом палітри: `--paper #FAFAFA`, `--ink #121212`,
  `--ink-dim #545454`, `--accent #821447` і окремий набір локального нічного світу.
- Нічна картка головної використовує `--world-*` ролі, не перевизначаючи базові
  `--paper` та `--ink`; друкований reset лишається світлим.
- Текстові пари проходять AAA ≥7:1; сильні межі — ≥3:1 у світлому й нічному світах.
- `npm run build`, `npm run check`, `npm run palette`, `npm run size`,
  `npm run validate` і `git diff --check` пройшли.

## Результат Phase 3

- Нічний scope застосовується на `/nichlyst/`, сторінці приватності гри та
  індексі й записах `/cemetery/` в обох мовах.
- Шапка та підвал лишаються світлими зонами переходу з виразними межами;
  друк повертає нічні сторінки до світлої схеми.
- Кадри гри не змінюються. Їхні темні краї відділені від полотна межами;
  логотип зберігає вбудований фон і отримує вільне поле та рамку.

## Візуальна база

Запитаний комплект знімків ще не знято. У згенерованому сайті зараз 29 маршрутів поза 404 (15 українських і 14 англійських), тоді як паспорт головної вказує 28 публічних сторінок. До знімання потрібно звірити, чи враховувати україномовний вірш без англійського дзеркала, та затвердити канонічний перелік маршрутів.

Вбудований браузер не надає керування viewport-ом; його єдиний пробний знімок має ширину 772 px і не є ні узгодженим desktop-, ні mobile-baseline. Системний Chrome не запускається у headless-режимі в цьому середовищі: `chrome_crashpad_handler: --database is required` (вихід 133). Тому не створював неповні або неправильно позначені знімки. Повний комплект UA/EN × mobile/desktop лишається блокером до доступу до браузера з viewport-емуляцією або робочого headless Chrome.
