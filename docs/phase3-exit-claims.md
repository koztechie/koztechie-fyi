# Критерій виходу Фази C: публічні твердження

Вихід із Фази C заборонений, доки кожне істотне публічне твердження не має
блокувального машинного gate або явного запису `ACCEPT` у
`docs/DECISIONS.md`. Декларативну політику не називати технічним примусом.

| Твердження | Класифікація | Gate / запис | Межа твердження |
|---|---|---|---|
| WCAG 2.2 AA | Машинний gate для автоматизованого обсягу | CI: A11y matrix, Pa11y/axe, Lighthouse accessibility error gate; локально `npm run check` | Публічна заява описує перевірки за критеріями, а не сертифікацію чи повне доведення відповідності. Ручні NVDA, VoiceOver, TalkBack, High Contrast, Zoom і reader-mode перевірки залишаються відкритими та зазначені в заяві. |
| AAA-контраст тексту | Машинний gate | `npm run palette` / `scripts/palette-check.mjs` | Текст ≥7:1; UI-текст перевіряється за AA ≥4.5:1, нетекстові межі — ≥3:1. |
| Бюджет сторінки ≤50 КБ | Машинний gate | `npm run check` і `npm run size` | Brotli-бюджет для HTML + активної CSS-пари + JS; без медіафайлів. |
| HSTS | Машинний gate | `scripts/check.mjs` перевіряє `_headers`; `npm run live-probe:light` перевіряє production response | Потрібні `max-age=31536000` і `includeSubDomains`; `preload` не заявляється. |
| noai / noimageai | Явний прийнятий ризик | `ACCEPT F42` у `docs/DECISIONS.md` §42.2 | Директиви `robots.txt` і `X-Robots-Tag` декларативні; вони не блокують непокірного бота. |

Жодна зелена автоматизована перевірка не замінює ручне підтвердження, якщо
межа твердження прямо вказує на незавершене ручне тестування. Не розширюй
заяви за межі наведених перевірок; нове твердження додай до цієї таблиці або
зафіксуй як окремий прийнятий ризик перед публікацією.
