# Візуальна система: Сигнал сховища

**Статус:** нова система, 2026-11-14. Цей документ замінює попередню палітру,
типографіку й композиційні правила. Джерело реалізації — `src/styles/`.

## 1. Напрям

Сайт — цифровий вузол записів. Інтерфейс має відчуватися як жива система
індексації: контрастне поле, сигнальні мітки, ясні стани, модулі з видимими
межами. Жодної імітації книжки, паперу, картотеки чи друкованого протоколу.
Жодного портфоліо-шаблону.

### Візуальні принципи

- Сильний контраст між навігаційним шаром і робочим полем.
- Великі гротескні заголовки; службові дані набираються моноширинним шрифтом.
- Інформація групується у модулі та індексні списки, а не в довгу одноколонкову
  стрічку.
- Колір позначає ієрархію та стан. Він не замінює підписів і тексту.
- Межі, тло та типографіка працюють як одна система; декоративні ефекти
  дозволені, якщо не погіршують читання, доступність або швидкість.

## 2. Палітра та ієрархія кольорів

Палітра має одне світле полотно, один темний нічний простір і один акцент.
Попередню назву полотна об’єднано з `--paper`; `--link` і `--focus` залишаються
лише семантичними alias-ами `--accent`. Статуси більше не залежать від окремого
зеленого чи попелястого кольору: активний стан має текстову мітку або вагу,
а закритий використовує `--ink-dim`.

| Токен | Значення | Роль |
|---|---|---|
| `--paper`, `--surface` | `#FAFAFA` | Єдине світле полотно |
| `--ink` | `#121212` | Основний текст |
| `--ink-dim` | `#545454` | Вторинний текст ≥14px, зокрема закриті записи |
| `--rule-soft` | `#E2E2E2` | Тихі роздільники |
| `--rule-strong` | `#8A8A8A` | Виразні світлі межі |
| `--accent` | `#821447` | Посилання, фокус, сигнатурні й документні акценти |
| `--link`, `--focus` | `var(--accent)` | Єдині підтримувані семантичні alias-и |
| `--night` | `#0F0F0F` | Тло локального нічного світу |
| `--text-night` | `#F2F2F2` | Основний текст нічного світу |
| `--text-dim` | `#A3A3A3` | Вторинний текст нічного світу |
| `--accent-night` | `#F08CB0` | Акцент нічного світу |
| `--rule-soft-night` | `#383838` | Тихі межі нічного світу |
| `--rule-strong-night` | `#686868` | Виразні межі нічного світу, контраст ≥3:1 |

Локальний темний світ активується атрибутом `data-world="night"` на компоненті.
Його змінні перевизначають ті самі ролі в `themes.css`; системна тема відвідувача
не перемикає палітру. На сторінці NICHLYST збережено оригінальні зображення й
логотип гри. Сильна нічна межа `#686868` має 3.44:1 проти `--night`; запропонований
`#5A5A5A` порога не досягає. `--ink-dim` затемнено з `#595959` до `#545454`,
щоб зберегти контраст AAA ≥7:1 на новому `--paper`.

### Чому ці кольори

Це візуальне прочитання [маніфесту](/manifest/): колір посвідчує, а не
рекламує. Кожен образ нижче прив’язаний до конкретної формули:

| Колір | Hex · L* · контраст | Образ і роль | Формула маніфесту |
|---|---|---|---|
| `--paper` | `#FAFAFA` | Єдине світле полотно | «Мати власний тихий куточок у мережі» |
| `--ink` | `#121212` | Текст як свідчення реальності | «Фіксувати реальність» |
| `--ink-dim` | `#545454` | Вторинний текст і закриті записи | «Без прикрас» |
| `--rule-soft`, `--rule-strong` | `#E2E2E2`, `#8A8A8A` | Тихі й виразні межі | «Мати власний тихий куточок у мережі» |
| `--accent` | `#821447` | Підпис, посилання й акцентні мітки | «Рекламним портфоліо» тут не бути |
| `--night`, `--text-night` | `#0F0F0F`, `#F2F2F2` | Локальний темний світ і його текст | «Фіксувати реальність» |
| `--text-dim`, `--accent-night` | `#A3A3A3`, `#F08CB0` | Другорядний текст і акцент нічного світу | NICHLYST |

Базова схема сторінок світла. Атрибут `data-world="night"` на `<body>` вмикає
нічну палітру для NICHLYST, його політики приватності й Кладовища; шапка та
підвал усередині цього scope перевизначають ролі на світлі. Картка NICHLYST
на головній використовує той самий локальний набір. `--text-dim` зберігає
контраст для вторинного нічного тексту, а `--accent-night` — для посилань і
фокуса. Друк нічних сторінок повертається до світлої палітри.

### Колірна схема

Сайт має контракт «лише світла схема»: ранній `<meta name="color-scheme" content="light">`
узгоджений із `color-scheme: only light` у CSS. `theme-color` і маніфест
використовують `--paper`; системна темна тема не перемикає палітру. Локальний
нічний світ активують лише компоненти з `data-world="night"`.

Для `prefers-contrast: more` вторинний текст і виразні межі стають чорнильними,
а посилання отримують товстіше підкреслення. У forced-colors стани спираються
на системні кольори, текстові мітки й підкреслення. `accent-color` для
нативних контролів відповідає `--accent`; виділення тексту використовує
контрастну пару поточного світу.

`npm run palette` перевіряє основний текст за AAA (7:1), текст інтерфейсу за
AA (4.5:1), а сильні межі й кільце фокуса — щонайменше 3:1 на відповідному
полотні. Для декоративних заливок текст не використовують без перевіреної
контрастної пари.
Chrome-селектори (`.site-header`, `.site-footer`, `.home-hero`) не можуть
використовувати `--accent` як фонову заливку.

## 3. Типографіка

Системні шрифти; без мережевих запитів заради гарнітури.

| Роль | Стек |
|---|---|
| Заголовки й інтерфейс | `system-ui`, `-apple-system`, `Segoe UI`, sans-serif |
| Текст записів | той самий гротескний стек |
| Метадані й код | `ui-monospace`, `Cascadia Code`, `Consolas`, monospace |

Базовий текст — 18px із міжряддям 1.65. Заголовки масштабуються плавно,
але не зменшують системний базовий кегль. Довгі фрагменти коду прокручуються
всередині власного блока.

Базове міжряддя задає `--leading` у `core.css`.

Автоматичні переноси звичайного тексту вимкнені (`hyphens: manual`), бо
українські словники нерівномірно підтримуються браузерами. Для заголовків
увімкнено `hyphens: auto` разом із `overflow-wrap: break-word`: браузер може
перенести довге слово за словником, а примусовий розрив лишається крайнім
запобіжником. Мови беруться з `lang` документа.

Ваги системних шрифтів залежать від ОС і доступних гарнітур. Заголовки
запитують `800`; за відсутності точної ваги браузер використовує найближчу
доступну, а `font-synthesis: none` не створює штучного накреслення. Цю
варіативність між Windows, Apple, Android і Linux прийнято як властивість
системного стека; однакова форма заголовків на всіх платформах не гарантується.

## 4. Композиція

- Контейнер сторінки — до 84rem; основний текст — до 40rem.
- `--container: 84rem` задає максимальну ширину основного контейнера й шапки;
  внутрішній заголовок має мінімальну висоту `--header-h: 4.5rem`.
- Головна — модульний огляд вузла: великий сигнальний герой, паспорт, принципи,
  індекс розділів, останній запис і окремий модуль NICHLYST.
- На широкому екрані модулі утворюють асиметричну сітку. На вузькому — один
  стовпець у логічному порядку документа.
- Сторінки записів мають виразну зону заголовка, дані запису та окреме поле
  основного тексту.
- Навігація присутня і помітна на кожному розмірі екрана. Мобільне меню
  прокручується горизонтально без прихованих пунктів.
- Шапка прокручується разом зі сторінкою, не закріплюється: так вона не
  відбирає вертикальний простір у вузького екрана. `scroll-padding-top` задає
  відступ для переходів до якорів.
- Стан `aria-current`, фокус клавіатури та попередження мають видимі,
  різні індикатори.

## 5. Рух та взаємодія

Рух не потрібен для розуміння сторінки. Мікроанімації дозволені лише як
короткий зворотний зв'язок і вимикаються для `prefers-reduced-motion`.
Hover ніколи не є єдиним способом дізнатися про стан.
Посилання постійно підкреслені й мають колір акценту. Відвідані посилання
додатково отримують подвійне підкреслення; під час наведення чи натискання
текст переходить до чорнила, а підкреслення потовщується. На темному блоці
NICHLYST стани зберігають контраст нічного тексту й акценту. CTA — контурна,
без заливки. Клавіатурний фокус має окреме 3px кільце з відступом.

У `forced-colors: active` чипи й сигнальні межі мають видимий системний
контур (`CanvasText`), а клавіатурний фокус використовує `Highlight`.
`forced-color-adjust` не вимикається: системна палітра користувача має перевагу.

## 6. Межі реалізації

- Vanilla CSS; нові пакети заборонені без `[ДОЗВОЛЕНО NPM]`.
- JavaScript на сайті — 0 байт.
- HTML + CSS + JS сторінки — не більше 50 КБ.
- Жодних зовнішніх шрифтів, скриптів, зображень або трекерів.
- WCAG AAA для тексту; видимий клавіатурний фокус; масштабування до 200%.
- Сторінка політики NICHLYST (`/nichlyst/privacy/` і `/en/nichlyst/privacy/`)
  використовує цю дизайн-систему та глобальні токени сайту.
- Окрема палітра `/nichlyst/` — Фаза B (PLAN 201–203); до її реалізації сторінка
  використовує поточну глобальну тему. CSS додається разом із реальною палітрою,
  без порожнього плейсхолдера.

### Умовні компоненти

Стилі станів, які з’являються лише за наявності відповідних даних, зберігаються
разом із шаблонною логікою й не вважаються зайвим CSS: `.content-warning`
залежить від поля `content_warning`, `.now-energy` — від числового `energy`,
`.translation-pending` позначає неповний переклад, а `.pagination__pages` і
`.pagination .current` виводяться для багатосторінкових списків. Частина цих
станів може бути відсутня в поточній збірці; їхні стилі потрібні, щоби
майбутній вміст не з’явився без оформлення.
