# Журнал уроків

Один відтворюваний дефект — один рядок. Записуй конкретний симптом, причину,
запобіжник і перевірний доказ; не зберігай тут секрети, приватні дані чи
перекази сесій. Детальні fixtures належать до `docs/drills.md`.
