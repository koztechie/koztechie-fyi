# Регламент супроводу

Цей регламент відповідає PLAN 280–286. Не створюй зміни лише заради календаря:
оновлюй статус і документи тільки підтвердженими фактами.

## Щомісяця

- Переглянь `content/uk/pages/now.md` і англійське дзеркало.
- Онови `/now/` лише якщо змінився підтверджений поточний стан; синхронізуй
  обидві мови й дату.
- Перевір останній production deploy та повідомлення про відомі блокери.

## Щокварталу

Запусти й зафіксуй результат:

```bash
npm run build
npm run qa:all
npm run check:determinism
npm run linkcheck
npm run live-probe:light
npm audit
npm audit --prefix scripts/tools
```

- Переглянь оновлення залежностей окремо для кореневого проєкту й
  `scripts/tools`. Не додавай npm-пакетів без прямого дозволу автора.
- Перевір зовнішні лінки в strict-режимі, якщо доступна мережа:
  `LINKCHECK_STRICT=1 npm run linkcheck:external`.
- Переглянь `docs/lessons.md`, `docs/drills.md` і відкриті записи в
  `docs/STATE.md`; закривай статус лише з доказами.
- Перевір DNS/поштовий канал за процедурами `docs/runbook.md` та
  `docs/infra-email.md`; не змінюй DNS без авторизованого доступу.

## Раз на пів року

- Перечитай чинні рішення й технічні стандарти; застарілі вимоги виправляй
  спершу в `docs/DECISIONS.md`, а тоді синхронізуй похідні документи.
- Перевір, що публічні твердження досі мають машинний gate або явний
  `ACCEPT`, згідно з `docs/phase3-exit-claims.md`.

## Щороку та перед довгою відсутністю

- Перевір продовження домену, TLS, 2FA та контакт відновлення.
- Перевір резервні копії й можливість відновлення за `docs/recovery.md`.
- Перед відсутністю понад два тижні переконайся, що сайт працює без нових
  публікацій і не залежить від ручного щотижневого втручання.

## Після зміни або інциденту

- Для коду/контенту пройди `docs/testing.md`; production-зміни публікуй лише
  штатним авторизованим процесом.
- Задокументуй відтворюваний дефект одним рядком у `docs/lessons.md`, а
  регресійний тест — у відповідному drill.
- Не редагуй `docs/PLAN.md` чи `docs/STATE.md` за припущенням: звір статуси з
  фактичними файлами, тестами й production-результатами.
