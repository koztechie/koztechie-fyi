# Шаблон сесії (SESSION TEMPLATE)

Готовий текст для запуску робочої сесії. Скопіюй у чат агента
(MiMo, Cursor, будь-якого) з робочою текою кореня репозиторію.
Місця `[...]` заповни перед запуском.

---

## Текст промпту

```text
Виконай це завдання професійно, найкращим чином, з тестами та верифікацією.
Якщо виконання неможливе без моєї дії — надай покрокову інструкцію з усіма
фрагментами контенту.

Протокол:
1. Прочитай docs/STATE.md і docs/PLAN.md.
2. Повідом поточний крок і фазу.
3. Виконай 1 крок. Максимум [3] за сесію, ≤ 90 хвилин.
4. Верифікуй: тести, перевірки, grep. Без «на вигляд працює».
5. Онови docs/STATE.md: лог сесії та поточний крок.
6. git commit (без перевизначення автора) + git push.
7. Заверши блоком «ЗМІНЕНІ ФАЙЛИ».

Обмеження:
- Мова відповіді: українська.
- Жодних заборонених слів (AGENTS.md §2, DECISIONS.md §28).
- Жодного знака оклику.
- Нові npm-пакети: лише з [ДОЗВОЛЕНО NPM].
- Файли поза переліком задач — не чіпати.
- docs/PLAN.md без моєї вказівки — не редагувати.

Енергія: [N]/10. Якщо ≤ 3 — лише тексти та docs, код заборонено.

Крок: [число з STATE.md]
```

---

## Варіанти заповнення

| Поле | Варіанти |
|------|----------|
| `[3]` | 1 (коротка сесія) / 3 (стандарт) / 7 (максимум) |
| `[N]/10` | Оцінка енергії. ≤ 3 — тексти, docs. ≥ 4 — код дозволено |
| `Крок:` | Число з `docs/STATE.md`, рядок «Крок» |

## Правило сирени (з `STATE.md` §2)

Тривога → `git add . && git commit -m "WIP: Сирена" && git push` → укриття.

## Після сесії

Агент оновлює `docs/STATE.md` сам. Якщо не оновив — онови вручну:
поточний крок, запис у лозі (дата, номер, файли, суть).

---

**Філософія:** Шаблон містить лише те, що не змінилося за 10 років.
Якщо змінився стек — зміни цей файл, не пам'ять агента.
