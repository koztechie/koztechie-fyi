# PLAN.MD: ПЛАН ЗАПУСКУ ВУЗОЛ-0

**Статус: ЗАТВЕРДЖЕНО** (аудит 2).

**Перевірка нумерації:** `node scripts/plan-lint.mjs docs/PLAN.md`

---

## Як працювати з планом

- Одна сесія OpenCode = **3–7 кроків**, максимум 90 хвилин.
- Кожен крок = одне завдання моделі або одна твоя дія. Після 1–3 кроків — `git commit`.
- В кінці фази — **Брама**. Браму не закрито — повторюй перевірку. Резервних кроків немає.
- У дні з енергією 1–3/10 — тільки «легкі» кроки (тексти, docs). Код — заборонено.
- Правило сирени: тривога → `commit && push` → укриття.
- Правило енергії: код лише в дні ≥ 4/10.
- Правило пріоритету NICHLYST: у хакатонні періоди гра перша; сайт у режимі очікування.
