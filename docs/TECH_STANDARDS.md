## 3. HTML

**Обов'язкові теги:** `header`, `nav`, `main`, `footer`. Решта — за потреби.

**Доступність:**
- `nav` — `aria-label`.
- Активний розділ — `aria-current="page"`.
- Skip-link «до змісту» (`<a href="#main" class="skip-link">`).

**Класи:** Логічні назви (`.archive-list`, `.entry-meta`). Без utility-класів (`mt-4`, `flex`).

- `style=""` в HTML (CSP `style-src 'self'`).
- `inline script` (CSP `script-src 'self'`).
- `subgrid` — лише якщо підтримується в Firefox ESR.

## 4. CSS

**Статус: ЗАТВЕРДЖЕНО** (крок 56, 2026-10-17).

### 4.0. Рукописний CSS. Кастомні властивості.

**Рішення:** Весь CSS — рукописний. Жодних препроцесорів, жодних фреймворків,
жодних генераторів utility-класів.

**Чому:**

| Аргумент | Пояснення |
|----------|-----------|
| Бюджет | ≤ 15 КБ CSS (§1). Кожен фреймворк перевищує бюджет до першої сторінки. |
| Машини | Сайт має працювати на A4-4020. Необроблений CSS не потребує збірки. |
| Аудит | Чистий CSS читається без інструментів. Через 5 років — теж. |
| Залежності | `AGENTS.md` §3: заборонені Tailwind, Bootstrap, будь-які CSS-фреймворки. |

**Заборонені препроцесори та генератори (всі):**

| Заборонено | Причина |
|------------|---------|
| Sass / SCSS / Less | Зайва збірка. Кастомних властивостей достатньо. |
| Tailwind | Utility-класи роздувають HTML і порушують бюджет 50 КБ. |
| Bootstrap | Фреймворк зі своїм думмінгом. Суперечить §4 «Заборонені патерни». |
| PostCSS (як залежність) | Без плагінів він не потрібен; з плагінами — це вже препроцесор. |
| CSS-in-JS | Потребує JS на клієнті. JS: 0 байт (§5). |

**Кастомні властивості — єдиний механізм абстракції:**

| Рівень | Механізм |
|--------|----------|
| Значення | `var(--bg)`, `var(--ink)`, `var(--accent)` — у `themes.css` |
| Теми | Одна група змінних у `@media (prefers-color-scheme: dark)` |
| Повторювані правила | Класи в `components.css`. Без міксинів. Без `@extend`. |
| Медіа-запити | Нативні. Без міксинів-мікромедіа. |

**Порядок завантаження** (6 файлів → 1 на виході):

```
core.css → layout.css → components.css → themes.css → print.css → nichlyst.css
```

`nichlyst.css` вантажиться лише на `/nichlyst/`. `print.css` — лише в медіа
`print`. Решта — загальним листом.

### 4.1. Архітектура

**6 файлів у `src/styles/`:**

| # | Файл | Призначення |
|---|------|-------------|
| 1 | `core.css` | Скидання, змінні, типографічна база |
| 2 | `layout.css` | Сітка, шапка, підвал |
| 3 | `components.css` | Картки, мітки, лінійки |
| 4 | `themes.css` | Значення палітр ПАПІР та БУНКЕР |
| 5 | `print.css` | Друк: завжди світла тема |
| 6 | `nichlyst.css` | Палітра NICHLYST. Лише в `nichlyst.njk` |

**Збірка:** На виході — один файл (скрипт без залежностей). Менше запитів на повільному каналі.

**CSS-змінні:** `var(--bg)`, `var(--surface)`, `var(--ink)`, `var(--ink-dim)`, `var(--accent)`, `var(--rule)`.

**Hex:** Заборонений скрізь, крім `themes.css` і `nichlyst.css`. `print.css` перевизначає змінні.

**Заборонені патерни:**
- `box-shadow`, `text-shadow`, `drop-shadow` — без винятків (фокус через `outline`).
- `linear-gradient`, `radial-gradient`.
- `backdrop-filter`.
- `border-radius` > 4px (§6 DECISIONS).
- `style` атрибути.

**Фокус:** `:focus-visible` — `outline: 2px solid var(--accent)`. Контраст індикатора ≥ 3:1 до фону в обох темах. Текст ≥ 7:1 (AAA).

**Гліч:** Лише 3 сигнатури (PLAN.md 94–96). Анімуй `transform`/`opacity`. Без властивостей, що викликають layout.

**`prefers-reduced-motion`:** Гліч і курсор ▍ вимикаються.

**Responsive:**
- 320 px (reflow, WCAG 1.4.10).
- 360 px.
- 1366×768.
- Зум 200%: лейаут не ламається.
- Шрифти в `rem`, не в `px`.

## 6. ШРИФТИ

**Статус: ЗАТВЕРДЖЕНО** (крок 58, 2026-10-17).

**Схема:** Системний стек для тексту + один самохостинговий woff2 для
моноширинних акцентів. Жодних сторонніх CDN (`AGENTS.md` §3, `DECISIONS.md` §36.1).

### 6.0. Системні стеки

**Текст (засічки)** — крок 87: «системний стек із засічками»:

```css
--font-text: Georgia, "Times New Roman", "Noto Serif", serif;
```

| Ланка | Чому |
|-------|------|
| Georgia | Є на Windows, macOS, iOS, Android. Найбільше покриття. |
| Times New Roman | Старий Windows та Linux з мовою. |
| Noto Serif | Linux без Georgia. |
| `serif` | Остання ланка. ОС обере сама. |

**Службове (без засічок)** — шапка, підвал, мітки:

```css
--font-ui: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
```

**Моноширинне (нативне)** — для коду, де woff2 не завантажився:

```css
--font-mono: ui-monospace, "Cascadia Code", "Courier New", monospace;
```

### 6.1. Самохостинговий woff2

**Один файл.** Моноширинний шрифт для акцентів (слогани, мітки, цифри).
Не два. Не три. Один.

**Вимоги:**

| Параметр | Значення |
|----------|----------|
| Формат | `woff2` |
| Сабсети | латиниця + кирилиця (одним файлом) |
| Вага | ≤ 60 КБ (`AGENTS.md` §3) |
| `font-display` | `optional` (`swap` дає CLS) |
| Місце | `static/fonts/` |
| Кодування | Brotli-сумісне |

**Unicode-range** — явно задай гліфи, які реально вживаються:

- `і ї є ґ` (кирилиця)
- Апостроф `ʼ`
- Лапки `«»`
- Тире `—`
- Символи дизайн-системи `▍ ≈ № → ▪`

Гліфи поза діапазоном падають на системний mono-стек. Це нормально.

**Fallback:** Підбери через `size-adjust` у `@font-face`, щоб не стрибала
висота рядка при завантаженні.

### 6.2. Чому так

| Аргумент | Пояснення |
|----------|-----------|
| Швидкість | Системні шрифти не завантажуються. 0 запитів. |
| Бюджет | Один woff2 ≤ 60 КБ вкладається в 130 КБ (§1). |
| Живучість | Georgia виживе довше за будь-який веб-шрифт. |
| CDN | Google Fonts заборонено (`AGENTS.md` §3). Чужий CDN — чужа точка відмови. |

### 6.3. Верифікація

| Перевірка | Межа |
|-----------|------|
| Запити до сторонніх доменів шрифтів | 0 |
| `.woff2` файлів | 1 |
| Вага `.woff2` | ≤ 60 КБ |
| `font-display` | `optional` |

## 8. БЕЗПЕКА ТА ПРИВАТНІСТЬ

**CSP:**
```
default-src 'self';
img-src 'self';
style-src 'self';
script-src 'self';
frame-ancestors 'none';
base-uri 'none';
form-action 'none'
```

**Заголовки:**
- `Strict-Transport-Security: max-age=31536000; includeSubDomains`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- `X-Content-Type-Options: nosniff`

**Кешування:**
- Ассети з хешем (`site.<hash>.css`): `Cache-Control: public, max-age=31536000, immutable`.
- HTML: `Cache-Control: max-age=0, must-revalidate`.

**Заборонено:**
- Будь-які запити до сторонніх origin (шрифти, CDN, пікселі, iframe, embed).
- `localStorage`, `sessionStorage`, cookies.
- `X-Frame-Options` (заміна: `frame-ancestors 'none'` у CSP).
- `maximum-scale`, `user-scalable=no` (viewport).

**EXIF:** Вирізати GPS, модель камери перед публікацією (§36.9 DECISIONS).

## 9. ДОСТУПНІСТЬ

**Фокус:** `:focus-visible` — `outline: 2px solid var(--accent)`. Контраст ≥ 3:1 до фону.

**Тач-цілі:** ≥ 44×44 px для окремих елементів керування. Інлайнові посилання в тексті — виняток.

**Viewport:** Без `maximum-scale`, без `user-scalable=no`.

**hreflang:** Взаємні, абсолютні, із self-reference та `x-default`. Без вказівки на `noindex`-заглушки. `rel="canonical"` на кожній сторінці. RSS auto-discovery для обох фідів.

**JSON-LD:** `Person`, `WebSite`, `BlogPosting`, `VideoGame`. `Person.name` — одне; решта форм в `alternateName`. `sameAs` — лише GitHub.

**Формат дат:** `Intl` для `uk-UA` додає «р.». Перевір результат і приведи до «16 жовтня 2026» через `formatToParts`.

**`prefers-reduced-motion`:** Гліч і курсор ▍ вимикаються.
