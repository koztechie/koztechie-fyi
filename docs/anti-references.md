## 2. Чому векторні макети, а не скриншоти

| Аргумент | Пояснення |
|----------|-----------|
| Авторське право | Скриншот чужого сайту в публічному репозиторії — правовий риск. Макет — власний твір |
| Живість | Сайти змінюються і зникають. SVG не залежить від чужого хостингу |
| Точність | Макет містить рівно ті порушення, які документуються. Скриншот містить зайве |
| Вага | 13 КБ на три макети. Скриншоти — мінімум 100 КБ |
| Інспекція | SVG — код. Кожен патерн видно в редакторі, він же і є доказом |
| Доступність | Рендериться будь-де, масштабується без втрати якості |

## 3. Як користуватися

1. Перед дизайном нової сторінки — переглянути три макети.
2. Якщо елемент схожий на один із трьох — він заборонений. Без обговорення.
3. Перед публікацією — звірити з `check.mjs` (автоматичні перевірки) та
   `design-system.md` §2 (повний перелік заборон).

## 4. Оновлення

Нові антиреференси додаються за тією ж схемою:

1. SVG у `anti-references/`, ≤ 10 КБ, з вбудованими позначками порушень.
2. Рядок у таблиці §1 з прив'язкою до розділів заборон.
3. Власний твір. Жодних скриншотів чужих сайтів.

Старі антиреференси НЕ видаляються: вони фіксують рівень, який проєкт
свідомо відкинув.
