```

**Правило:** Один канонічний URL (§18). Якщо есей «100 днів: що змінилося» (§9, тема 6) вже перенесено — це той самий текст. Не дублюй.

```

**dev.to після перенесення:** На кожній статті dev.to постав `canonical_url` → URL на fyi. Сайт не посилається на dev.to (§3).
